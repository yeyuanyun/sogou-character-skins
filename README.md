# 安魂曲·新月摇篮曲

以《异环》安魂曲为主题的 Windows 搜狗输入法皮肤，版本 1.3。

## 安装

下载 [安魂曲-新月摇篮曲.ssf](安魂曲-新月摇篮曲.ssf)，双击并在搜狗输入法的安装窗口确认。更新时重新安装即可。

## 功能

- 横排、竖排候选框，配托腮立绘与番茄睡眠挂件。
- 中英文双头像随输入状态切换；下方中／英按钮切换语言。
- 番茄按钮切换全半角：有番茄为全角，无番茄为半角。
